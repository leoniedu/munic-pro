Backup JSON

Exporta o histórico inteiro guardado nesta instalação, no mesmo formato do botão "Backup JSON" do painel — um arquivo de qualquer um dos dois pode ser importado pelo outro.

Importar backup

Lê um arquivo de Backup JSON e mescla o conteúdo com o histórico já guardado. Linhas e leituras já presentes são identificadas e ignoradas — importar o mesmo arquivo mais de uma vez não duplica o histórico. Um arquivo que não seja reconhecido como backup não altera nada.

Limpar histórico

Apaga todo o histórico guardado nesta instalação. Não pode ser desfeito — faça um Backup JSON antes, se quiser guardar os dados.
