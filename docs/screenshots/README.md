# Capturas para a Chrome Web Store

A loja exige pelo menos **uma** captura de **1280×800** (ou 640×400).
Nenhuma pode ser gerada daqui — precisa da página real, autenticada.

## O que capturar

1. **Painel aberto, aba Município** — mostra o que a extensão faz de mais
   evidente: a linha de botões azul-escuro como segunda linha da linha de
   botões do próprio SIGC, e abaixo o painel com as cinco abas, uma coluna
   por data e as situações coloridas.
2. *(opcional)* **Aba Assistência %** — mostra o agrupamento por
   assistência, que é o que o relatório de 2025 fazia.

## Como

- Janela do Chrome em 1280×800 (`⌘⌥I` → ícone de dispositivo → Responsive
  → digitar 1280 × 800), ou capturar maior e redimensionar.
- Rodar **Relatório-PRO** antes, para a tabela ter dados de verdade.
- Salvar aqui como `painel-municipio-1280x800.png`.

## Atenção

A captura vai para uma listagem pública. Município, agência e situação de
coleta não são dados pessoais, mas confira que não há nome de pessoa nem
nada de identificável no enquadramento antes de enviar.

## Já capturada

`painel-agencia-pct-1280x800.png` — aba Agência %, com a linha de botões,
as cinco abas, a coluna de data e as situações coloridas. O nome do
usuário no cabeçalho do SIGC foi tapado, e o dock do macOS recortado:
a listagem é pública.

Falta ainda, se quiser uma segunda imagem: a aba **Município**, que é a
que mostra para que serve a extensão — uma linha por município,
questionário e indicador, com uma coluna por leitura.
